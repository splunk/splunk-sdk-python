# splunk-mcp-poc

This example aspires to verify the points listed in an internal "POC - AI with Splunk Apps" doc

## Pre-requirements

- Python 3.10+
- `uv`
- A way of launching Jupyter notebooks

## Getting started

- Run `uv sync`
- `source .venv/bin/activate`
- Run the code blocks `bin/mcp_enabled_app.ipynb`
